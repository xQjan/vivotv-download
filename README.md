## Installation auf dem Fernseher

1. Die App **Downloader** aus dem Play Store installieren.
2. In Downloader diese Adresse eingeben:
   ```
   https://github.com/xQjan/vivotv-download/raw/main/vivotv.apk
   ```
3. Die Installation bestätigen (beim ersten Mal Downloader das Installieren unbekannter Apps erlauben).
4. vivotv öffnen und die Zugangsdaten des eigenen IPTV-Anbieters eingeben.

## Updates

Neue Versionen meldet die App selbst: In der Seitenleiste erscheint **„Update verfügbar“**. Ein Klick lädt das Update herunter, die eigenen Daten bleiben erhalten.

Voraussetzung: Android TV ab Android 7.0. Die App bringt keine Inhalte mit – sie braucht den Zugang eines Anbieters.
